## 1. What This Model Does

A **permutation-selection model** -- not a per-trade signal generator.

Given all trades generated by the upstream strategy, it answers:
"On which (symbol, day-of-week, time-of-day) slots should we actually be trading?"

A slot is defined as:
    slot = (symbol, day_of_week, time_bucket)

- symbol: ES, NQ, FDAX, CL
- day_of_week: 0=Mon 1=Tue 2=Wed 3=Thu 4=Fri 6=Sun
- time_bucket: 30-minute interval index (0=midnight, ascending)

Total active slots: ~920 (those with >= 20 trades in training).

NOT a trade entry/exit model. NOT a stop-loss system. NOT position sizing.
Flat capital per slot -- equal allocation, no confidence-based sizing.

---

## 2. Research Question

> "Which permutation to use per time of the day / day of the week that will
> generate overall results with Sortino > 3?"

Sortino is measured at the **daily portfolio level**, annualized by sqrt(252).
This is the standard fund-management convention, not per-trade Sortino.

## 5. Model Specification

### Bayesian Hierarchical Model (4-level partial pooling, NCP v3)

Sufficient-statistic formulation: reduces 2.8M trades to ~920 slot-level
observations per fold.

```
obs[i] ~ Normal(mu_slot[i], slot_se[i])

mu_slot[i] = alpha
           + beta_sym[sym_i]
           + beta_day[day_i]
           + beta_bkt[bkt_i]
           + beta_slot[sb_i]

alpha        ~ Normal(mu_data, 0.5*sigma_data)   # tighter prior

# All 4 levels: fully non-centered parameterization (v3)
sigma_sym    ~ HalfNormal(sigma_data)
beta_sym_raw ~ Normal(0, 1, shape=n_syms)
beta_sym     = beta_sym_raw * sigma_sym

sigma_day    ~ HalfNormal(0.5*sigma_data)
beta_day_raw ~ Normal(0, 1, shape=n_days)
beta_day     = beta_day_raw * sigma_day

sigma_bkt    ~ HalfNormal(0.5*sigma_data)
beta_bkt_raw ~ Normal(0, 1, shape=n_bkts)
beta_bkt     = beta_bkt_raw * sigma_bkt

sigma_slot   ~ HalfNormal(0.3*sigma_data)
beta_slot_raw~ Normal(0, 1, shape=n_sb)
beta_slot    = beta_slot_raw * sigma_slot
```

obs[i] = slot mean PnL. slot_se[i] = slot_std / sqrt(slot_n).

### Inference Settings (v3 -- final attempt)

- Sampler: NumPyro NUTS via PyMC5 (nuts_sampler='numpyro')
- 4 chains, tune=2000, draws=1000, target_accept=0.95
- PYTENSOR_FLAGS=cxx= mandatory (see Engineering Fixes)

### BH-FDR (Primary Gate -- Bayesian sampler intractable)

- One-sided t-test per slot: t = slot_mean / slot_se
- Benjamini-Hochberg FDR correction at Q=0.01 (static training selection)
- Only positive-mean slots tested
