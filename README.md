## 1. What This Model Does

This is a **permutation-selection model** -- not a per-trade signal generator.

Given all trades already generated by the upstream strategy, it answers:
*"On which (symbol, day-of-week, time-of-day) combinations should we actually be trading?"*

A **slot** is defined as:

    slot = (symbol, day_of_week, time_bucket)

- `symbol` in {ES, NQ, FDAX, CL}
- `day_of_week`: 0=Mon, 1=Tue, 2=Wed, 3=Thu, 4=Fri, 6=Sun
- `time_bucket`: 30-minute interval index (0=midnight, ascending through the day)

Total active slots: ~920 (those with >= 20 trades in training).

**What it is NOT:**
- Not a trade entry/exit model
- Not a stop-loss / take-profit system
- Not a position-sizing model (equal capital per slot -- flat allocation)

## 2. Research Question

> "Which permutation to use per time of the day / day of the week that will generate
> overall results with Sortino > 3?"

The Sortino ratio is measured at the **daily portfolio level**, annualized by sqrt(252).
This is the standard fund-management convention for reporting risk-adjusted returns.

## 5. Model Specification

### Normal Hierarchical Model (4-level partial pooling)

```
alpha        ~ Normal(mu_data, 2 * sigma_data)       # global intercept
sigma_sym    ~ HalfNormal(sigma_data)
beta_sym     ~ Normal(0, sigma_sym, shape=n_syms)    # symbol effects
sigma_day    ~ HalfNormal(0.5 * sigma_data)
beta_day     ~ Normal(0, sigma_day, shape=n_days)    # day-of-week effects
sigma_bkt    ~ HalfNormal(0.5 * sigma_data)
beta_bkt     ~ Normal(0, sigma_bkt, shape=n_bkts)   # time-bucket effects
sigma_slot   ~ HalfNormal(0.3 * sigma_data)
beta_slot    ~ Normal(0, sigma_slot, shape=n_sb)     # symbol x bucket interaction

mu_slot[i]   = alpha + beta_sym[sym_i] + beta_day[day_i]
              + beta_bkt[bkt_i] + beta_slot[sb_i]

obs[i]       ~ Normal(mu_slot[i], slot_se[i])        # CLT sufficient statistics
```

`obs[i]` = slot mean PnL (computed over all trades in that slot for that fold).
`slot_se[i]` = slot_std / sqrt(slot_n).

This reduces the problem from 2.8M individual trades to ~920 slot-level observations per fold.

### Inference Settings

- Sampler: NumPyro NUTS via PyMC5 (nuts_sampler='numpyro')
- 4 chains, 1000 tune steps, 1000 draws
- Target accept delta = 0.9
- Explicit initialization from data mean (avoids multimodal cold-start failures)
- PYTENSOR_FLAGS=cxx= (mandatory -- see Engineering Fixes)

### Per-Slot Posterior Sortino

For each slot after sampling:
1. Draw 2000 samples of mu_slot from posterior
2. mu_lo90 = 10th percentile of those draws
3. ds_mu = std of negative draws
4. sortino_lo90 = mu_lo90 / ds_mu
5. Slot passes primary gate if sortino_lo90 > 1.0

### Frequentist Supplement: BH-FDR

Parallel gate used as primary result (Bayesian convergence was inconsistent):
- One-sided t-test per slot: t = slot_mean / slot_se
- Benjamini-Hochberg FDR correction at Q = 0.01 (static) or Q = 0.05 (rolling)
- Only positive-mean slots tested

## 7. Model Iteration History

### Attempt 1: Regularized Horseshoe Prior -- FAILED

- Problem: Horseshoe creates a funnel geometry. When global scale tau -> 0, all NUTS
  proposals are rejected. With cxx= (Python-mode PyTensor), initial point evaluation
  produces degenerate gradients.
- Result: All 4 chains frozen at initialization. R-hat = 31,633,592 (sentinel value
  for zero within-chain variance). ESS = 4. Zero candidates in all folds.

### Attempt 2: Normal Hierarchical Prior -- PARTIAL CONVERGENCE

- Better: Log-concave posterior, no funnel geometry.
- Problem: Multimodal in some folds due to weakly-identified global intercept alpha
  when slot-level variance is very large (slot PnL std up to $2,250).

Convergence by fold:

| Fold | R-hat max | ESS min | Converged | Candidates |
|---|---|---|---|---|
| 1 (fold_i=0) | 31,633,592 | 4 | No | 178 (model artifact) |
| 2 (fold_i=1) | 31,633,592 | 4 | No | 3 |
| 3 (fold_i=2) | 31,633,592 | 4 | No | 3 |
| 4 (fold_i=3) | 3.74 | 4 | No | 0 |
| 5 (fold_i=4) | 1.11 | 29 | Partial | 32 |

Note: Fold 1 showing 178 candidates is a model artifact -- slots with only 4 trades
have posteriors dominated by the prior and capped at a boundary value of 90.00.

### Resolution: BH-FDR as Primary Gate

Given Bayesian convergence issues, the Benjamini-Hochberg FDR t-test becomes the
primary candidate selector. It is deterministic, statistically sound, and directly
interpretable as signal-to-noise ratio.

## 16. Environment and Requirements

### Critical: PyTensor Workaround (MUST NOT SKIP)

The host machine has a 32-bit MinGW C compiler while Python is 64-bit.
PyTensor's lazylinker tries to compile C extensions at runtime, which crashes.
The fix -- add this as the VERY FIRST lines of any script importing pymc or pytensor:

```python
import os
os.environ["PYTENSOR_FLAGS"] = "cxx="
```

NumPyro handles the actual sampling via JAX, bypassing PyTensor C entirely.

### Installation

```bash
pip install pymc numpyro jax jaxlib arviz pandas numpy scipy pyarrow
```

See requirements.txt for pinned versions.
